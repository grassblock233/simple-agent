# 侧边栏、工作台、设置与模型上下文修改总结

记录日期：2026-09-30。

本文汇总本次会话中的所有修改，以当前工作区实现为准，涵盖侧边栏交互、工作台紧凑化、模型上下文修复、设置工作台重写及最后一轮视觉复核。此前的 `2026-09-29-webui-optimization.md` 保留为历史记录；其中的设置弹窗、正文宽度和旧尺寸描述已被本文中的最终实现替代。修改尚未提交 Git，原有工作区改动未被撤销。

## 1. 项目和会话侧边栏

### 数据与排序

- 会话新增 `pinned`、`archived` 字段。读取旧会话时补为 `false`，保持旧数据可用。
- 项目新增独立元数据，保存于 `.data/projects.json`，记录工作目录、显示名称、置顶和隐藏状态。项目路径作为标识，默认名称取目录名；重命名仅修改显示名称，不修改实际目录。
- 项目置顶优先；项目内部会话和最近会话按置顶状态、更新时间排序。最近列表最多显示五项。
- 归档会话和隐藏项目从默认侧边栏中过滤。空会话仍沿用首次发送后才出现在历史列表的行为。
- 移除项目会隐藏项目并归档关联会话，不删除工作目录和会话文件；项目恢复接口可恢复整个项目及关联会话。

### 交互与浮层

- 项目悬停或聚焦时显示详情卡：项目名、项目置顶按钮、当前可见任务数量、工作目录和编辑入口。
- 项目行三点菜单提供置顶、编辑、文件管理器打开、归档聊天、移除项目。
- 项目列表和最近列表中的会话均显示标题、相对更新时间、所属项目详情，并提供置顶与删除按钮。删除继续使用确认框和现有删除接口，会永久删除对应会话记录，不删除工作目录文件。
- 详情卡和菜单通过 Portal 渲染，避免被侧栏滚动区域裁剪。按视口边缘限制位置，菜单与详情卡互斥；支持 Escape、点击外部关闭、键盘聚焦，菜单打开时聚焦首项。
- 桌面使用鼠标悬停；移动端增加项目和会话详情按钮，不依赖 hover。
- 项目详情卡与会话详情卡宽 360px，项目菜单宽 232px，小型浮层圆角 14px；移动端宽度受视口减 24px 限制。
- 保留侧栏默认宽 276px、拖拽调整、折叠、展开及本地状态保存。

## 2. 工作台紧凑化

- 集中定义正文宽度、水平边距、按钮尺寸、圆角和浮层阴影变量，未使用页面整体缩放。
- 品牌区及顶栏高 56px；新聊天行高 36px、下方间距 16px；最近分组顶部间距 20px；顶栏水平内边距 20px。
- 正文和输入框共用最大 800px 的居中宽度，桌面水平边距至少 24px，移动端 16px。移除正文依赖 `24vw` 和输入框按百分比计算的不同宽度规则。
- 使用主内容区容器宽度和对称滚动槽，修复滚动条造成的正文、输入框左右不齐。
- 正文字号 15px、行高 1.65；普通事件间距 20px，用户消息后 32px，思考及工具条目后 6px。
- 输入框圆角 18px，桌面最小高度 96px、文本区最小高度 54px、底部外边距 16px；保留多行自动增高、最大高度、附件和停止生成。
- 搜索弹窗最大宽 600px、圆角 16px，桌面顶部位置为 `clamp(72px, 18vh, 144px)`；输入行 48px、字号 16px，结果和快捷操作行 36px。

## 3. DeepSeek 模型上下文修复

依据 `/home/grass/Desktop/docs/` 中六份 DeepSeek API HTML 文档，重点核对思考模式、多轮对话、工具调用、模型规格和图像输入协议。

- 携带 `tools` 的请求保留历史助手消息的 `reasoning_content`，包括没有实际调用工具的最终回答。旧消息缺少该字段或字段为 `null` 时，发送空字符串；不修改已存储的原始历史。
- 纯文本用户消息只发送协议要求的 `role` 和 `content`，不携带内部 `images` 元数据；有图片时继续转换为文本和 `image_url` 内容块。
- `CONTEXT_TOKEN_BUDGET` 默认由 64000 改为 1000000，与本地模型文档标注的 1M 一致；配置限制在 4000–1000000，界面初始预算和 README 同步更新。
- 改进 token 估算：ASCII 按约四字符一个 token，非 ASCII 字符按更保守的方式计入；思考内容、摘要和消息结构参与估算，每张图片额外计入 1024。该值仍为估算，不是服务端 tokenizer 或实际 usage。
- 压缩优先保留最近三轮；不足三轮但存在可释放的完整历史时也可压缩。保留历史超过预算的 80% 时，进一步减少完整轮次，至少保留当前用户轮次。
- 压缩只在用户轮次边界切分，不拆散助手工具调用及对应工具结果；原始消息仍留在会话文件中，通过 `contextStart` 控制发送范围。
- 摘要长度限制为预算的 20% 对应字符数且不超过 6000 字符，降低摘要自身占满较小预算的风险。
- 取消操作在压缩开始、摘要失败处理和写入前检查；取消不再被当作普通摘要失败并生成降级摘要，不推进上下文起点。
- 压缩后上下文估算仍达到预算时停止请求，给出新建会话或提高预算的明确提示，避免继续发送明显超限的历史。

## 4. Codex 风格设置工作台

### 页面结构与状态

- 设置由覆盖聊天的居中弹窗改为工作台内完整页面。左侧为固定 240px 分类导航，右侧独立滚动，包含常规、外观、模型连接、当前会话、已归档的聊天五类。
- 常规为通常入口；没有 API Key 时直接进入模型连接。顶部保留返回聊天按钮和设置搜索。
- 搜索匹配设置名称与描述，按分类显示匹配控件；清空后恢复原分类，支持无结果状态。
- 聊天和侧栏保持挂载，设置打开时隐藏并设为 `inert`。保留草稿、附件状态和 Agent 运行状态；进入时记录聊天滚动位置，返回时恢复位置及设置入口焦点。
- 移除旧弹窗遮罩、焦点锁定和主要专用样式。Escape 在搜索有内容时先清空搜索，否则返回聊天。
- 移动端使用顶部返回栏、搜索框及分类选择器，内容水平边距 16px，长说明和控件允许换行。

### 常规、模型连接与当前会话

- 新会话默认设置包含思考强度、上下文压缩、失败次数和压缩阈值，初始值为高、开启、3 次、75%。逐项保存，保存失败回滚并显示错误。
- 默认设置仅影响新创建的会话；已有会话和复用的空会话不被覆盖。旧会话缺失设置字段仍补历史默认值，不继承后来修改的全局默认值。
- 模型连接保留固定模型 `deepseek-flash`、配置状态、Key 输入、显隐和保存。密钥继续仅存于服务端进程或环境变量，不写入设置文件或浏览器外观偏好。
- 当前会话提供可操作的思考强度选择器、压缩开关、失败次数步进器和阈值滑块。运行期间禁用修改，无会话时显示空状态。

### 外观与归档

- 主题支持浅色、深色、跟随系统；密度支持紧凑和舒适。默认浅色、紧凑，保存于浏览器 `simple-agent:appearance`。
- 首次绘制前应用主题；监听系统主题变化、本地存储变化和页面内偏好更新。深色覆盖聊天、侧栏、设置、弹窗、浮层、输入区与代码块。
- 舒适密度增大列表行高、设置行及事件间距，不整体放大字体。
- 已归档聊天按更新时间倒序显示，可按标题或项目搜索，提供恢复中、空状态、成功和失败反馈；恢复后更新侧栏并停留在设置页面。
- 单会话恢复会同时解除所属项目隐藏状态，仅恢复所选会话，其他归档会话不变。本次未新增已移除项目管理或归档页删除入口。

## 6. API、存储与主要文件

| 接口 | 改动 |
| --- | --- |
| `GET /api/projects` | 返回项目显示名称、置顶及隐藏元数据 |
| `POST /api/projects` | 按 `action` 执行 `rename`、`pin`、`archive`、`remove`、`restore`、`open` |
| `GET /api/sessions` | 列表返回 `pinned`、`archived` 和原有会话字段 |
| `PATCH /api/sessions/:id` | 支持置顶、归档和单会话恢复；运行中返回 409 |
| `GET /api/settings` | 返回 `{ sessionDefaults: SessionSettings }` |
| `PATCH /api/settings` | 接收部分 `sessionDefaults`，校验后合并并保存 |

- `.data/settings.json`：新会话默认设置，通过锁和临时文件替换保存。严格校验思考强度枚举、布尔压缩开关、1–10 整数次数和 0.1–0.95 数值阈值；不允许额外设置字段。
- `src/app/sidebar-list.tsx`：项目及会话列表、排序、Portal 详情和菜单。
- `src/app/settings-workbench.tsx`：分类、搜索、设置控件、保存反馈和归档恢复。
- `src/app/appearance.tsx`、`src/app/layout.tsx`：外观偏好、系统主题同步及首次绘制主题处理。
- `src/app/page.tsx`、`src/app/globals.css`：工作台状态衔接、紧凑布局、主题、密度与统一控件样式。
- `src/app/api/[...path]/route.ts`、`src/lib/store.ts`、`src/lib/types.ts`：项目元数据、设置持久化、归档恢复、接口与类型。
- `src/lib/model.ts`、`src/lib/context.ts`、`src/lib/agent.ts`：模型协议、上下文估算、压缩和预算保护。
- `tests/settings.test.ts`、`tests/sessions.test.ts`、`tests/context.test.ts`、`tests/agent.test.ts`：默认设置、归档、兼容、模型请求和压缩回归测试；README 更新预算说明。
