# Simple Agent 实施总结

记录日期：2026-09-29。项目从空仓库建立为可本地运行的 TypeScript + Next.js 代码生成 Agent。需求依据是 `/home/grass/Desktop/docs/codegen-agent-REQUIREMENTS.md`；模型固定使用 DeepSeek OpenAI 兼容接口的 `deepseek-flash`。

## 已完成的功能

- **本地工作台**：WebUI 支持浏览或输入任意已有本机目录，创建、切换、删除会话；会话绑定工作目录并以 JSON 持久化到 `.data/sessions`。页面展示流式回答、折叠的思考过程、工具入参与结果、成功/失败、耗时、上下文占用和压缩摘要。支持代码高亮与复制、示例任务、停止生成，以及思考开关、压缩阈值、失败尝试与工具轮数设置。
- **Agent 循环**：调用 DeepSeek `/chat/completions` 流式接口，按工具索引组装分段返回的多个工具调用，逐一执行并按调用 ID 回填。带工具的历史请求保留 `reasoning_content`。生成或修改代码后推动验证；失败有次数上限并报告命令与最后错误。模型服务的鉴权、额度、限流、超时和中断会形成可读提示。
- **工具与图片**：实现列目录、内容检索、读文件、写文件、Shell 执行和工作区图片分析。上传的 PNG、JPEG、GIF、WebP 经文件头、解码和尺寸检查后作为图文用户消息发送；工作区图片由独立视觉请求分析，结果以文本返回主 Agent。
- **上下文与恢复**：较早历史仅在完整用户轮次边界压缩，保留最近三轮和完整的工具调用/结果配对；压缩失败时生成本地精简摘要并标注降级。完整审计事件仍可在界面查看。停止、审批拒绝和服务中断不会把悬空工具调用送入下一次模型请求。同一工作目录的文件工具与 Shell 操作串行化。
- **安全边界**：文件工具拒绝目录穿越、符号链接、常见凭据文件、过大或二进制文本；修改已有文件要求本轮先读。每条 Shell 命令都需在 WebUI 人工批准，执行有超时、输出上限、危险命令拦截和环境变量白名单。**已批准的 Shell 命令以当前用户权限运行，可能访问工作目录之外；没有操作系统级沙箱。**
- **运行配置**：提供 `.env.example`、README 和 npm 脚本。没有 API Key 时仍可启动并管理会话；Key 可在设置中临时填写，只留在服务端进程，不传给工具子进程。服务默认只监听 `127.0.0.1`，面向本机单用户。

## 文件与架构

- `src/app/page.tsx`、`globals.css`：会话、目录选择、输入、附件、事件时间线、审批和设置界面。
- `src/app/api/[...path]/route.ts`：会话、目录浏览、图片、配置、审批、停止与 NDJSON 运行流的 HTTP 接口。
- `src/lib/agent.ts`、`model.ts`、`context.ts`：运行循环、DeepSeek 协议、重试、上下文压缩。
- `src/lib/tools.ts`、`files.ts`、`shell.ts`：工具调度、文件路径与图片校验、受审批约束的 Shell 执行。
- `src/lib/store.ts`、`types.ts`：会话、事件及图片存储和共享类型。
- `src/lib/origin.ts`：变更请求的同源检查。后续修复了选择 `/home/grass/Desktop/deepseek-harness` 时的“跨来源请求被拒绝”：以浏览器请求的 `Host` 和协议校验 `Origin`，不再直接比较 Next.js 可能使用内部地址的 `nextUrl.origin`；真正的跨站请求仍会拒绝。
