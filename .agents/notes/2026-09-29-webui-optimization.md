# WebUI 优化总结

记录日期：2026-09-29。本文汇总当天围绕参考截图完成的界面、交互及其必要的会话设置改动；以当前工作区实现为准。已有未提交改动保留。

## 工作台与会话

- 改为灰白色工作台布局：项目/会话侧栏贴齐视口左侧，聊天区贴齐右侧；桌面端侧栏可拖动宽度、折叠和恢复，状态保存在浏览器本地存储，手机端使用抽屉式侧栏。折叠及回弹遵循系统减少动态效果设置。
- 顶栏移除了“新建会话”加号及相邻分隔线；侧栏“新聊天”和无会话空状态入口保留。新聊天优先使用最近项目，同项目已有空白会话时复用；空白会话在首次发送前不出现在历史和搜索结果中。
- 项目下的对话列表保持挂载，以高度和透明度过渡展开或收起；折叠后使用 `inert`、`aria-hidden` 阻止隐藏按钮获得焦点，同时保留箭头旋转和 `aria-expanded`。搜索弹窗保持挂载，遮罩与弹窗约 200 ms 淡入、位移及反向退出；关闭后不可被键盘访问，打开时聚焦搜索框。搜索支持 `Ctrl/Cmd+K`、方向键、Enter 和 Esc。
- 对话内容采用居中窄列：宽屏最大约 900px，中等宽度两侧约 12vw，手机两侧约 20px；用户消息、助手回答和工具记录共用该宽度。输入框也同步内收，桌面最大约 900px、约占可用宽度的 88%，手机两侧约 16px，未引入横向滚动。

## 设置弹窗

- 原右侧抽屉改为约 720px 的居中弹窗，窄屏自适应，分为“模型连接”和“当前会话”标签页；默认显示模型连接。支持遮罩和 Esc 关闭、打开聚焦、关闭后恢复焦点、键盘切换标签页，并提供约 200 ms 的进退场动画与减少动态效果适配。
- 模型连接显示固定模型 `deepseek-flash` 和密钥配置状态；密钥输入可显示或隐藏，保存成功或失败在弹窗内反馈。密钥仍只保存在服务端进程中。
- 当前会话显示思考强度、上下文压缩开关、范围为 1–10 的失败尝试步进控件及 10%–95% 的压缩阈值滑块；无会话时显示空状态，运行中禁用不可修改项。Shell 授权提示仍在弹窗内。会话设置逐项保存；通过保存期间保持控件外观稳定并同步局部状态，修复修改设置后的闪烁。

## 输入区与图片

- 空白会话在输入框上方显示内缩约 32px 的灰色项目栏，与白色输入框居中衔接；有消息后隐藏该栏。项目入口可搜索已有项目或通过现有目录选择器选择目录，并打开或创建该目录的聊天。分支入口只读，可搜索本地分支、查看当前分支和未提交文件数；非 Git 目录显示空状态。没有加入分支切换或“本地”入口的额外操作。
- 保留左下角加号上传图片。附件使用固定缩略图容器、`object-fit: contain` 和独立移除按钮；对话中的图片按原始比例与可用宽度约束显示，修复低宽度图片布局。支持纯图片发送。输入框随内容增高，有高度上限；无文本且无图片时发送按钮禁用并显示灰色，有可发送内容时显示深色，运行中变为停止按钮。
- 右下角环形控件显示估算的上下文占用；悬停或键盘聚焦时显示百分比、已用标记数和总预算。其旁显示固定 DeepSeek 模型名称及思考强度，点击打开紧凑滑块，可选“关闭、低、高、最大”并可恢复默认。上下文提示与思考强度弹窗均收紧尺寸，适配窄屏。

## Agent 与数据兼容

- 删除“工具轮数上限”设置、PATCH 字段和 Agent 循环的轮数终止条件；用户仍可停止生成，失败尝试上限仍生效。读取旧会话时忽略 `maxToolRounds`。
- 用 `reasoningEffort` 替代旧的 `thinking` 开关：旧值开启迁移为“高”，关闭迁移为“关闭”；低、高、最大分别向 DeepSeek 发送对应的 `reasoning_effort`，关闭时禁用思考模式。模型仍固定为 `deepseek-flash`。
- 会话详情 API 返回上下文预算，供界面结合现有标记估算计算容量提示；新增 Git 状态只读 API，在验证工作目录后读取分支和未提交文件数。

## 主要文件

- `src/app/page.tsx`、`src/app/globals.css`：弹窗、侧栏、输入区、附件、响应式布局和动画。
- `src/app/api/[...path]/route.ts`：会话设置、上下文预算和 Git 状态接口。
- `src/lib/agent.ts`、`src/lib/model.ts`、`src/lib/store.ts`、`src/lib/types.ts`：取消轮数限制、思考强度协议及旧设置迁移。
- `src/lib/git.ts`：Git 与非 Git 目录的只读状态探测。
- `tests/agent.test.ts`、`tests/sessions.test.ts`、`tests/git.test.ts`：思考强度请求、超过原 16 轮、旧设置兼容和 Git 状态测试。
