# Simple Agent

本地运行的代码生成 Agent。通过 WebUI 选择工作目录，向 DeepSeek 提出文字或图片需求，观察文件操作、测试命令和修复过程。

## 启动

需要 Node.js 22 或更高版本、npm、可访问 DeepSeek API 的网络环境。仅面向本机单用户使用。

```bash
npm install
cp .env.example .env.local
npm run dev
```

打开 `http://127.0.0.1:3000`。在 `.env.local` 填写 `DEEPSEEK_API_KEY`，或启动后在设置中填写 Key。后者仅保存在当前服务端进程内，重启后需要重新输入。没有 Key 时应用仍能启动、管理会话及浏览目录。

默认模型固定为 `deepseek-flash`，思考模式默认开启。`DEEPSEEK_BASE_URL` 默认是 `https://api.deepseek.com`。`AGENT_DATA_DIR` 默认是项目下的 `.data`，保存会话 JSON 和上传图片；该目录已被 Git 忽略。`CONTEXT_TOKEN_BUDGET` 是本地压缩触发预算，默认 1000000，与模型文档的 1M 上下文长度一致，可配置为 4000–1000000。界面显示的 token 用量是估算值，中文和思考内容均计入。`SHELL_TIMEOUT_MS` 默认 30000，限制在 1000–120000 毫秒。

生产模式：

```bash
npm run build
npm run start
```

服务默认只监听 `127.0.0.1:3000`。不要将其通过反向代理公开：应用没有多用户身份验证，且能访问本机目录。

## 使用

1. 点击“新建会话”，浏览或输入已有目录的绝对路径。目录在创建会话时绑定，之后要操作另一个目录请新建会话。
2. 输入代码任务，可附加最多 4 张 PNG、JPEG、GIF 或 WebP 图片，每张最多 8 MiB。工作区已有图片可让 Agent 调用 `inspect_image` 分析。
3. 观察流式回复及工具记录。工具详情可展开查看入参、结果、状态和耗时；思考内容默认折叠。
4. 每条 Shell 命令出现授权卡后，核对完整命令与会话顶部的工作目录，再批准或拒绝。需要时点击停止按钮中断生成。

示例：`写一个判断回文字符串的函数并带上单测，运行测试并报告结果。`

## 安全边界

文件工具对每个路径进行工作区范围和符号链接检查，并拒绝常见凭据文件。读写文本单文件上限 64 KiB；过大或二进制文件需改用检索定位。修改已有文件前，Agent 本轮必须先读取它。

**Shell 没有操作系统级目录隔离。** 每条命令都需人工批准，但批准后会以当前用户权限运行，可能访问所选工作区外的文件和网络。明显的提权、关机、递归删除危险路径及网络传输命令会被拦截；这项检查不能替代人工审查。Shell 子进程只接收少量常规环境变量，不接收 API Key。执行限时、限制输出，失败和拒绝都会回传给 Agent。

## 架构

浏览器通过 Next.js Route Handler 管理会话、上传图片，并用 NDJSON 流接收运行事件。服务端 Agent 逐轮请求 DeepSeek Chat Completions；完整收集模型回复后执行所有工具调用，将每个调用 ID 对应的结果回填。工具调用与结果作为一个完整批次进入后续模型历史。停止时未完成的模型输出不入历史；已产生的工具调用会得到成功、失败或停止结果。

会话及审计事件原子写入 `.data/sessions`。上下文接近阈值时，仅在完整用户轮次边界压缩较早历史，保留最近三轮；界面保留完整审计历史。压缩失败后使用本地精简摘要并标注降级。思考模式与工具同时启用时，未压缩的所有历史 `reasoning_content` 原样回传给 DeepSeek。工作区图片通过单独的视觉请求分析，再将文本结果交给主 Agent。

## 常见问题

- **提示未配置 Key**：在设置中填写 Key，或在 `.env.local` 设置后重启服务。
- **鉴权失败或额度不足**：检查 DeepSeek 控制台的 Key 和余额；设置面板可在不重启应用的情况下替换 Key。
- **找不到文件或被拒绝**：确认会话绑定的工作目录、路径及符号链接。会话目录在创建后不会自动改变。
- **命令卡住**：Shell 默认 30 秒超时，输出限制 24,000 字符；可以停止当前运行并调整任务。
- **压缩后如何核对历史**：时间线仍保留原始事件；压缩事件可展开查看摘要和被压缩的消息范围。
